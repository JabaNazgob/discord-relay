Модуль для FoundryVTT, который передаёт события из голосового канала другим модулям или вашим макросам через открытый API. **Без Discord-бота.**

Поддерживается на версиях FoundryVTT v13 и v14

## Установка

1. В главном меню Foundry, во вкладке "Модули" нажмите "Установить модуль", и вставьте в поле снизу ссылку-манифест:
   ```
   https://github.com/JabaNazgob/discord-relay/releases/latest/download/module.json
   ```
2. После, в вашем мире Foundry, включите модуль **Discord Relay: Voicechat Hooks & Macros** в окне "Управление модулями"

## Возможности

### Среди передаваемых событий голосового канала:

- Вход/выход из голосового канала
- Пользователь начал/закончил говорить
- Пользователь выключил микрофон/звук
- Модератор выключил пользователю звук/микрофон
- Профиль пользователя был изменён (никнейм, аватарка и т.п.)
- Один раз при запуске ретранслятора/смене канала: название и пользователи голосового канала

Все эти события передаются через API модуля. Также, вы можете использовать простые макросы, используя эти события. Об этом будет написано ниже

### Помимо этого, модуль может следующее:

- Привязка профиля Discord к пользователю FoundryVTT
- Журнал событий и визуальное отображение голосового канала в окне модуля

## Использование

### Подключение (кратко)

Для запуска ретранслятора вам нужно совершить несколько простых действий после установки модуля, в его окне. **Эти действия может выполнить любой из ваших игроков:**

1. **Один раз от лица ГМа:** Указать ссылку нужного голосового канала Discord в окне модуля
2. Установить [TamperMonkey](https://www.tampermonkey.net/) в браузер
3. В параметрах расширения в браузере разрешить пользовательские скрипты (в некоторых браузерах это может называться иначе, например "Разрешить сценарии пользователей")
4. Добавить [скрипт](https://github.com/JabaNazgob/discord-relay/raw/main/discord-relay.user.js) в TamperMonkey (если TamperMonkey уже стоит, по ссылке он сам предложит установку)
5. **В том же браузере** запустить нужный мир в Foundry, открыть меню модуля, и нажать "Включить ретранслятор"

**Примечание:** пользователь-ретранслятор сам должен находиться в голосовом канале чтобы получать события "Начал/закончил говорить"

Сразу несколько игроков могут быть ретрансляторами. Если один из игроков внезапно отвалится, другой его автоматически заменит.

Подробный гайд будет внизу этого файла. Он также продублирован внутри самого окна модуля

### Макросы событий

В окне модуля есть вкладка "Макросы". В ней вы можете выбрать нужное вам событие голосового канала Discord как триггер, макрос, который должен выполняться при этом триггере, область выполнения (например "Для всех" или "Только от лица Мастера") и максимальную частоту срабатывания (например, чтобы избежать частого срабатывания при событии "Начал говорить")

<details>
<summary><b>Памятка: что доступно в макросе</b></summary>

Макрос пишется как обычный скрипт-макрос, без `Hooks.on`. Все данные события лежат в одной переменной `discordEvent` (она же `scope.discordEvent`): `discordEvent.type`, `discordEvent.member` и т.д. Поля такие же, как в аргументах крюков модуля. Если данных нет, в поле `null`. Кнопка ▶ у правила запускает макрос прямо сейчас у вас, с тестовыми данными, — удобно проверить макрос без Discord.

**Для всех событий**

| Переменная | Что в ней |
|---|---|
| `discordEvent.type` | Какое событие сработало: `"joined"`, `"left"`, `"muted"`, `"unmuted"`, `"deafened"`, `"undeafened"`, `"updated"`, `"speakingStart"`, `"speakingStop"`, `"channelLoaded"`, `"relayStarted"`, `"relayStopped"` |
| `discordEvent.member` | Участник Discord: `id`, `nick`, `name`, `avatarUrl`, `mute`, `deaf` (общие: сам или модератор), `selfMute`, `serverMute`, `selfDeaf`, `serverDeaf`, `speaking`, `bot` (для событий участника) |
| `discordEvent.foundryUser` | Пользователь Foundry, привязанный к участнику (первый), или `null` |
| `discordEvent.foundryUsers` | Все пользователи Foundry, привязанные к участнику (массив) |
| `discordEvent.channel` | Голосовой канал: `id`, `guildId`, `name`, `topic`, `userLimit` |
| `discordEvent.members` | Все участники голосового канала (массив, как `member`) |
| `discordEvent.rule` | Правило, которое запустило макрос |
| `speaker, actor, token, character` | Обычные переменные Foundry |

**Для отдельных событий**

| Переменная | Что в ней |
|---|---|
| `discordEvent.previous` | muted / unmuted / deafened / undeafened / updated: данные участника до изменения |
| `discordEvent.changed` | muted / unmuted / deafened / undeafened / updated: только изменившиеся поля, например `{mute: true, selfMute: true}` или `{nick: "Вася"}` |
| `discordEvent.reason` | speakingStart / speakingStop: `null`, если событие пришло от Discord; `"left"`, `"relayLost"` или `"snapshot"`, если его отправил модуль. channelLoaded: `"relayStarted"`, `"channelChanged"`, `"reconnected"`, `"relayChanged"` или `"clientJoined"` |
| `discordEvent.relayUser` | relayStarted / relayStopped: пользователь Foundry, запустивший или остановивший ретранслятор |
| `discordEvent.test` | Проверочный запуск (кнопка ▶ у правила): `true`, иначе `false` |

**Пример (правило «начал говорить», у Мастера)**

```js
// Написать в чат, кто начал говорить
const name = discordEvent.foundryUser?.name ?? discordEvent.member.nick
const p = document.createElement("p")
p.textContent = `${name} говорит` // как текст: в нике могут быть < и >
ChatMessage.create({content: p.outerHTML})
```

### API

Модуль отдаёт события через крюки Foundry и объект `game.modules.get("discord-relay").api`. В нём есть текущий состав канала, связи профилей Discord с пользователями Foundry и открытие окна модуля.

```js
const api = game.modules.get("discord-relay").api
Hooks.on(api.hooks.MEMBER_SPEAKING_CHANGED, (member, speaking, context) => {
    console.log(member.nick, speaking ? "начал говорить" : "замолчал", context.foundryUser?.name)
})
```

**Полное описание и подробности:** [API-ru.md](API-ru.md) (по-русски), [API.md](API.md) (in English)

## Полная инструкция по Подготовке и активации ретранслятора

### Перед началом:

- Ретранслятор можно запустить только в браузере. В приложении FoundryVTT он не работает — модуль сам это распознает и подскажет
- Ретранслятор должен быть активен хотя бы у 1 пользователя. Примечание: даже если вы хостите FoundryVTT через приложение, вы можете сами стать ретранслятором, зайдя в мир через браузер другим пользователем

### Термины

- Ретранслятор: скрипт, который запускается в браузере, и передаёт события из голосового канала Discord в FoundryVTT
- Игрок-ретранслятор: игрок, который запустил ретранслятор

Все дальнейшие действия должен совершить игрок-ретранслятор.

### 1) Установка и настройка TamperMonkey

- Установите расширение [TamperMonkey](https://www.tampermonkey.net/) в браузере, и включите его
- После установки, перейдите в настройки расширений браузера, и установите параметры расширения TamperMonkey в зависимости от используемого браузера:
  - Mozilla Firefox: активно по умолчанию
  - Opera GX: «Подробнее» → «Разрешить пользовательские скрипты»
  - Chrome: «Сведения» → «Разрешить пользовательские скрипты»
  - Microsoft Edge: «Разрешить сценарии пользователей»
  - Если у вас другой браузер, или отсутствуют настройки с таким названием, попытайтесь найти аналогичные настройки, если в панели управления TamperMonkey всё ещё присутствует надпись «Разрешите пользовательские скрипты»

### 2) Установка скрипта

- Откройте [скрипт по этой ссылке](https://github.com/JabaNazgob/discord-relay/raw/main/discord-relay.user.js) или нажмите кнопку «Установить скрипт» во вкладке «Руководство» окна модуля. Откроется новая вкладка, и TamperMonkey предложит установить скрипт
- Нажмите «Установить» (или «Обновить», если скрипт уже стоит). Старая версия скрипта заменится сама
- Убедитесь, что в панели управления TamperMonkey скрипт «Streamkit Speaking Relay» включён

**Если не сработало: установка вручную**

- Откройте панель управления TamperMonkey и нажмите [+] (создать новый скрипт). Если скрипт «Streamkit Speaking Relay» уже есть — откройте его вместо создания нового
- Скопируйте [скрипт](discord-relay.user.js), замените им ВЕСЬ текст в редакторе и сохраните: <kbd>Ctrl</kbd> + <kbd>S</kbd>

### 3) Запуск ретранслятора

- Зайдите в мир FoundryVTT через браузер, в котором установлен скрипт, и откройте окно модуля. Открыть его можно через настройки модуля, кнопку в Театре модуля VisualNovelDialogues или командой `game.modules.get("discord-relay").api.openMenu()`
- Мастер указывает ссылку на голосовой канал во вкладке «Ретранслятор» (ПКМ на канал в Discord → «Копировать ссылку»)
- Нажмите «Включить ретранслятор». Откроется окно StreamKit. Если Discord попросит разрешить доступ StreamKit — разрешите
- Состояние «Работает» означает, что всё в порядке. Если что-то пошло не так, во вкладке «Ретранслятор» будет написано, что именно и как это исправить

### Примечания:

- Вы должны находиться в этом голосовом канале, чтобы получать события «Начало речи» и «Конец речи»
- Не закрывайте окно StreamKit, пока идёт игра: при закрытии ретранслятор остановится. Свернуть окно можно
- Если вы перезагрузите страницу FoundryVTT, ретранслятор сам подхватит уже открытое окно StreamKit

### Интеграция с VisualNovelDialogues

Модуль VisualNovelDialogues автоматически получает события ретранслятора. Вы можете настроить поведение модуля VisualNovelDialogues при получении им этих событий в его настройках. По умолчанию, при событиях «Начало речи» и «Конец речи» модуль VisualNovelDialogues будет подсвечивать Портреты персонажей соответствующих игроков. Для корректной работы, проследуйте инструкции ниже

**Подготовка**

- Во вкладке «Ретранслятор» окна модуля установите пользователям FoundryVTT соответствующие профили Discord
- В списке игроков FoundryVTT (обычно, слева снизу) нажмите на имя игрока, и выберите «Настройки участника». В открывшемся окне, выберите соответствующего актёра в качестве Персонажа игрока
- Далее, откройте редактор нужного вам Портрета, и во вкладке «Общие данные» свяжите с этим портретом соответствующего актёра
- Теперь, когда этот Портрет будет находиться в Театре, он будет подсвечиваться когда соответствующий игрок будет говорить. Вы можете настроить яркость и размер "подсвечиваемого" Портрета в настройках модуля VisualNovelDialogues
